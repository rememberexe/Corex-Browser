# Corex Browser

Corex Browser, C# ve WPF kullanılarak geliştirilen modern bir Windows web tarayıcısıdır.

Tarayıcı altyapısı Microsoft WebView2 teknolojisini kullanır ve modern, sade ve kullanıcı dostu bir tarayıcı deneyimi sunmayı hedefler.

## Özellikler

* Modern ve sade kullanıcı arayüzü
* Sekmeli tarayıcı sistemi
* Her sekme için bağımsız WebView2 örneği
* Yeni sekme oluşturma ve sekmeleri kapatma
* Yeni pencere isteklerini uygulama içerisinde yeni sekme olarak açma
* Adres çubuğundan URL veya arama yapabilme
* Kalıcı oturum ve cookie desteği
* Tarayıcı kapatılıp açıldığında oturum bilgilerinin korunması
* İndirme sistemi
* Aktif indirmelerin takip edilmesi
* İndirme ilerleme durumunun görüntülenmesi
* Birden fazla indirme desteği
* İndirmeleri duraklatma, devam ettirme ve iptal etme
* Tamamlanan dosyaların bulunduğu klasörü açabilme
* Tarama geçmişi altyapısı
* Yer imleri için geliştirmeye uygun yapı
* Fluent UI System Icons kullanımı

## Kullanılan Teknolojiler

* C#
* .NET
* WPF
* Microsoft WebView2
* Fluent UI System Icons

## Projenin Amacı

Corex Browser, modern web tarayıcılarının temel çalışma mantığını anlamak ve Windows üzerinde kendi tarayıcı deneyimini oluşturmak amacıyla geliştirilmektedir.

Projede özellikle sekme yönetimi, WebView2 entegrasyonu, indirme işlemleri, yeni pencere yönetimi ve kullanıcı arayüzü üzerinde çalışılmıştır.

Yeni pencere açma istekleri mümkün olduğunca uygulama dışına çıkmadan Corex Browser içerisinde yeni sekmeler olarak yönetilir. Bu sayede kullanıcı, tarama deneyimini tek bir uygulama içerisinde sürdürebilir.
